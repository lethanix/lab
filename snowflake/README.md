# Snowflake Lab

Exploration and learning of Snowflake Data Cloud, following two main resources: 

- The book [Snowflake Data Engineering](https://www.manning.com/books/snowflake-data-engineering), of Maja Ferle.
- The skill track [Snowflake Foundations](https://www.datacamp.com/tracks/snowflake-foundations) available in Datacamp.

Modified SnowSQL queries from the book are in the `book/` directory. Queries and scripts from the skill track and experiments are in `exploring/`.
